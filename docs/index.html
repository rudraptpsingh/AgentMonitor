Telemetry Architecture

Engineered to monitor the dark corners of AI agent execution.

Tab 1 · Processes

Process Tree & Zombie Reaper

Coding agents regularly leave detached helper processes (`node`, `python`, `zsh`) whose parent exits, reparenting them to `init`/`launchd` (PPID=1). AgentMonitor sweeps and reaps them with one click, freeing locked ports and `.git/index.lock`.

Signals SIGSTOP · SIGCONT · SIGTERM
Tab 2 · Tokens

Token Burn & 5-Hour Quota

Detects prompt-cache invalidation before your quota is wiped out. Tracks live token burn rates against Anthropic's rolling 5-hour rate limits, displaying remaining window reset time and safe headroom.

Prompt Caching Hit Ratio Auditor · Rolling Reset
Tab 3 · Filesystem

Filesystem & 15ms Merkle Rewind

Before an agent runs destructive commands, AgentMonitor captures a zero-copy shadow Merkle snapshot. If the agent hallucinates or breaks files, rewind that specific turn in 15ms without touching your own manual commits.

Rollback Speed < 15 ms Snapshot Restore
Tab 4 · Tool Calls

Tool Calls & Wire Tap

Real-time tap into JSON-RPC 2.0 tool invocations (`Bash`, `FileEdit`, `AskUser`, `MCP`). Inspect command inputs, stdout responses, true latency, and scrub outgoing credentials (`sk-ant-...`, AWS keys) before they enter session logs.

Protocol MCP stdio · SSE · JSON-RPC
Tab 5 · Startup Tax

Startup Tax & Context Meter

Audits static cold-start token consumption from `CLAUDE.md`, `AGENTS.md`, `.cursorrules`, and MCP schemas against the 200k context window. Shows exact token weight per file to prevent displacing reasoning scratchpads.

Tokenizer Exact BPE cl100k_base Count

Developer Controls

Native keyboard shortcuts.

Key Combination Action Scope
⌘1 – ⌘5 Switch tabs (Processes, Tokens, Filesystem, Tool Calls, Startup Tax) Global
⌘R Reap all detached zombie child processes (PPID=1) Global
Space Pause / resume selected agent process (SIGSTOP / SIGCONT) Processes Tab
⌘K Terminate selected agent and its entire descendant process tree Processes Tab
⌘⌥Z Instant Rewind: Restore working tree to selected checkpoint turn Filesystem Tab
⌘F Focus live search / filter input Global
